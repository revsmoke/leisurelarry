# Historical reference assets

Open `index.html` to browse 44 historical screenshots and two Softporn instruction scans. Complete source URLs, credits, platforms, dimensions, download status and hashes are recorded in `../docs/references.json`. Findings and adaptation recommendations are in `../docs/research.md`.

These files are for historical study only and are not production assets. `.gdignore` excludes this directory from Godot imports. All images retain their original source attribution. No game binary or disk image was downloaded. Some images contain mature humor.
